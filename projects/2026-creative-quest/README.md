# Creative Quest

**Status:** arquivado · **Início:** abril 2026

App experimental para estimular a criatividade: uma lição por dia durante 28 dias, memórias com foto de cada lição e arquivo de lições.

## Versões

- [`index.html`](index.html): v2, que adiciona a área *Session*, com timer Pomodoro e sessões de desenho com imagem de referência.
- [`v1.html`](v1.html): primeira versão, com lição do dia, memórias e arquivo.
